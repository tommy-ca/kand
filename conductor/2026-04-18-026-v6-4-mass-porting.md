# Implementation Plan: V6.4 - Mass Porting of Core Indicators

## Overview
Building upon the finalized `kand_indicator!` Universal Macro Engine (V6.3), this phase focuses on the rapid mass porting of remaining technical indicators to the durable stateful/batch framework.

## Scope
We will systematically convert the following categories of indicators using the macro:
1. **Percentage & Ratio Oscillators**: `ROCP`, `ROCR`, `ROCR100` (similar to `ROC`).
2. **Moving Averages**: `WMA`, `RMA`, `DEMA`, `TEMA`, `TRIMA`, `T3`.
3. **Simple Transforms**: `MEDPRICE`, `TYPPRICE`, `WCLPRICE`.
4. **Basic Oscillators**: `BOP`, `CCI`, `MFI`, `DX`.

## Strategy
For each indicator:
1. Identify its type (`recursive` or `sliding_window`).
2. Replace manual `Stateful` and `Batch` implementations with `kand_indicator!`.
3. Retain the `_raw` loop implementation for the functional `lookback` processing.
4. Verify parity through TDD (`cargo test`).
5. Ensure `prek` quality gate passes.
6. Commit atomically with semantic messages (`feat(scaling): port X to macro engine`).

## Quality Assurance
- **TDD Parity**: Ensure macro-generated stateful/batch results numerically match the functional baseline.
- **Subagent Audit**: Utilize `codebase_investigator` to ensure no manual stateful boilerplates are left behind.
- **Performance**: Track overhead via `cargo bench --bench bench_arrow`.

## Next Steps
1. Port the `ROC` variants (`ROCP`, `ROCR`, `ROCR100`).
2. Port `RMA` and `WMA`.
3. Port Price Transforms (`MEDPRICE`, `TYPPRICE`, `WCLPRICE`).
